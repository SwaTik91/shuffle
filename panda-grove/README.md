# Роща Панды

Светлый браузерный слот 5×3 в китайской теме. Панда, бамбук и веер вместо драконов. Фейковые кредиты, те же правила, что у «Свитка Дракона».

## Как открыть

Из этой папки:

```bash
npm test
python3 -m http.server 4174
```

Затем открой http://localhost:4174/

На GitHub Pages: https://swatik91.github.io/shuffle/panda-grove/

Чтобы сразу увидеть бонус: `?demo=bonus`. Линию: `?demo=line`.

Raffle-страницы репозитория `shuffle` эта игра не меняет.
