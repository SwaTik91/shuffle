# Свиток Дракона

Браузерный видеослот 5×3 в китайской теме. Фейковые кредиты, правила в духе Book of Ra, свои название и символы.

## Как открыть

Из этой папки:

```bash
npm test
python3 -m http.server 4173
```

Затем открой http://localhost:4173/

Либо просто открой `index.html` в браузере (нужна поддержка ES-модулей).

Чтобы сразу увидеть бонус: `http://localhost:4173/?demo=bonus` и нажми «Крутить».

Raffle-страницы репозитория `shuffle` эта игра не меняет.
